# DocFerry Support

- Product support: [DocFerry Support](https://docferry.bondie.io/dashboard/support)
- Email: `support@bondie.io`

Use product support for login, membership refresh, sharing, importing,
subscription, receipt, cancellation, and refund-status questions.

GitHub issues are suitable for reproducible client defects using sanitized
steps. Do not paste tokens, account identity, private note content, payment
details, provider references, Checkout URLs, or environment values.

Security reports follow [SECURITY.md](SECURITY.md).
