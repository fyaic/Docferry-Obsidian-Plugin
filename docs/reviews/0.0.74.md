# 0.0.74 Review Checklist

## Scope And Cause

The only runtime source change from 0.0.73 is in `plugin/src/settings.ts`.
Lockfiles also update the COS XML parser dependency to `@xmldom/xmldom@0.8.15`
and audit-tool dependencies to `fast-uri@3.1.8` and `js-yaml@4.3.2`, closing
the advisories detected during candidate preparation. Dependency ranges and
the COS SDK version remain unchanged. Release checks now validate lockfile
root versions too, preventing the stale 0.0.72 metadata found in 0.0.73.

On Obsidian 1.13+, a non-empty `getSettingDefinitions()` replaces `display()`;
it does not merely add global search entries. Returning an empty list retains
the complete imperative settings page, also used on 1.12.7.

This deliberately withdraws four incomplete native search entries. A complete
declarative migration is future work; removing account and sharing controls to
satisfy a search recommendation is not acceptable. No review rules are disabled.

## Trust Review

- Plugin ID, minimum host, MIT license, optional-payments classification,
  service origin, and privacy/data flows remain unchanged.
- The change does not modify authentication, SecretStorage, entitlement checks,
  payment handling, publication, imports, or user configuration.
- Server billing navigation is a separate deployment. Do not describe the
  client package as resolving monthly-to-yearly portal configuration.

## Reproducible Build

```sh
npm ci
npm --prefix plugin ci
npm run build
npm run check:release
npm audit --omit=dev
npm --prefix plugin audit --omit=dev
```

Check that root and plugin manifests/package versions are 0.0.74, both version
maps specify 1.12.7, and the tag is exactly `0.0.74` without a prefix.
The tag workflow must succeed, attest all three runtime assets, and leave the
release in draft. Download draft assets with repository access and compare
their full SHA-256 values to the source build before product-team approval.
