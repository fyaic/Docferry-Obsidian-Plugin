# DocFerry 0.0.35

DocFerry now connects to the formal Bondie production service and keeps the
main workflow deliberately small: share the current note, import a supplied
link, manage existing shares, or check the connected account.

This release adds:

- Pro Folder Share with revision, navigation, password, asset, update, and stop
  boundaries.
- Bounded Full Theme support with a safe reader-theme fallback.
- Membership refresh after Checkout and Account Center changes.
- Public web-link import with link-only fallback when detailed processing is
  not enabled.
- Safer Folder Share capacity and asset-maintenance behavior.

The plugin remains free to install. Free limits are shown in the Account page;
optional Pro subscriptions are managed through Bondie Account and Stripe.
Managed media providers are not advertised unless the production runtime has
separately enabled and qualified them. Provider keys never enter the plugin.
