# DocFerry 0.0.36

This is the formal Bondie production release of the DocFerry Community plugin.

It includes the novice-first dashboard, secure single-note sharing, share
import and management, paid Folder Share, bounded Full Theme support, reliable
membership refresh after billing changes, and link-only public web import.

The plugin is free to install. Optional Pro subscriptions are managed through
Bondie Account and Stripe. Managed media providers remain unavailable unless
the production runtime separately qualifies and enables them; provider keys
never enter the plugin.
