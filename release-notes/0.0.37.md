# DocFerry 0.0.37

This release fixes the Community plugin login endpoint for the current free
DocFerry service.

- Use `https://docferry.fuyonder.tech` as the default production service for
  new Community installs.
- Migrate old unauthenticated installs that still point to
  `https://docferry.bondie.io` so Login and Create account open the correct
  current service.
- Keep existing connected accounts untouched during migration.
- Refresh public documentation and privacy links to the current service.
