DocFerry 0.0.38
================

This is a corrective Community release for the public free-launch plugin line.

- Restores the 0.0.21 free-launch UI and release boundary.
- Keeps public billing disabled.
- Uses `https://docferry.fuyonder.tech` as the current free production service.
- Migrates unauthenticated installs that still point to
  `https://docferry.bondie.io` back to `https://docferry.fuyonder.tech`.

Existing connected accounts are not rewritten by the migration.
