DocFerry 0.0.39
================

This corrective Community release keeps the public free plugin on the Fuyonder
DocFerry service only.

- Removes the remaining legacy service runtime path from the plugin bundle.
- Resets older or non-current service settings to
  `https://docferry.fuyonder.tech`.
- Clears stale session, account, and membership state during that reset so users
  reconnect through the current free service.
- Keeps public billing disabled.
