DocFerry 0.0.40
================

This corrective Community release keeps the public free plugin on the Fuyonder
DocFerry service and fixes the free sharing flow.

- Fixes access refresh parsing when the free service response does not include
  billing metadata, so sharing is not blocked by `billing.enabled` runtime
  errors.
- Keeps the file explorer right-click share action labeled `Share thru
  Docferry`.
- Renames the command palette action to `Share current note` to avoid stale
  publish wording while satisfying Obsidian command naming rules.
- Keeps public billing disabled and the service locked to
  `https://docferry.fuyonder.tech`.
