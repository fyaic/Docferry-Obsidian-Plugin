# DocFerry 0.0.67

This corrective release hardens the full DocFerry paid product before the next
Obsidian Community rollout.

## Security And Account Reliability

- Binds browser login completion to the initiating plugin with S256 PKCE.
- Keeps pending-login verifiers and product sessions in Obsidian SecretStorage.
- Continues email-verification signup in the original DocFerry flow.
- Makes account switching transactional and clears login timers on unload or
  disconnect.

## Share And Import Reliability

- Rechecks current membership for paid mutations and extractive Advanced
  Import instead of trusting stale cached access.
- Serializes quota decisions and preserves Advanced Import idempotency across
  retries.
- Preserves legacy Share references and asks before a one-way republish to the
  current service.
- Repairs Share metadata lifecycle behavior for moved notes, inactive history,
  dead links, and fresh republishing.
- Preserves completed Advanced Imports for later review and derives supported
  YouTube covers deterministically.

## Privacy And Experience

- Aligns direct object-storage upload disclosure across the plugin, public
  privacy policy, and hosted service.
- Restores the intended login action after authentication and keeps dialogs
  usable in narrow Obsidian windows.
- Updates Community-facing copy for the Free core, optional Pro subscription,
  Folder Share, theme styling, and Advanced Import.

DocFerry requires Obsidian 1.12.7 or newer. Login opens in the system browser;
normal users do not copy a code or approve an Obsidian external-action URL.
