# DocFerry 0.0.68

This corrective release ships the plugin security and reliability fixes that
were closed on the paid mainline after the `0.0.67` public package was built.
Users on `0.0.67` receive this update through the Obsidian Community
directory.

## Security

- Filters hidden and traversal-encoded asset references before publishing, so
  a malicious note cannot upload `.obsidian` configuration or files outside
  the vault through crafted image paths, and lists what was skipped.
- Cancels any pending login poll when an account switch's logout fails, so a
  later poll can no longer silently complete the sign-in behind the user's
  back.
- Serves the browser confirmation pages that host sign-in and sign-out forms
  with a same-origin referrer policy, so the enforced origin binding accepts
  real browsers instead of rejecting every legitimate confirmation.
- Requires explicit per-device account selection before approval during
  browser-based login.

## Share Reliability

- Makes share creation idempotent: a lost connection followed by a retry now
  resumes the same publish instead of creating a duplicate public link, and
  the same guarantee covers the fallback re-publish used when an existing
  share disappeared concurrently.
- Preserves legacy share references behind an explicit migration decision and
  keeps the stop-sharing confirmation from being bypassed.
- Rechecks fresh membership before paid mutations and extracts the exact
  publish/update state machine for stopped, moved, and dead-link shares.

## Account And Quota Experience

- Keeps session tokens and pending login verifiers in Obsidian SecretStorage
  with lifecycle-safe timers.
- Hides the Folder Share entry on Free plans and warns before an Advanced
  Import consumes one of the remaining monthly allowances.
- Preserves completed Advanced Imports for later review and resolves the
  cancel-versus-review race on finished import jobs.
