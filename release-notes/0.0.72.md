# DocFerry 0.0.72 Community Review Candidate

This is the paid DocFerry plugin candidate prepared for product-team review.
It has not been tagged, released, or submitted to the Obsidian Community
directory.

## Reliable Shares Across Surfaces

- Lets an Obsidian vault explicitly claim and update an older Share created by
  DocFerry CLI or MCP when that Share did not yet record a vault identity.
- Keeps one active link per account and source across Obsidian, CLI, and MCP,
  including retries, renamed notes, and recovered Folder Share drafts.
- Preserves ownership, source, and vault compare-and-set checks so copied or
  stale frontmatter cannot claim another Share.

## Complete Folder And Media Assets

- Publishes local images, audio, video, attachments, wiki links, Markdown
  links, and supported raw HTML references through the same Share pipeline.
- Repairs images reused by multiple notes in one Folder Share and prevents an
  unresolved reference from being paired with the wrong uploaded asset.
- Keeps media players and their safe attributes in the public reader while
  continuing to remove scripts, event handlers, unsafe URL schemes, and
  iframe embeds.
- Warns when a local attachment format cannot be published instead of silently
  omitting it.

## Account And Plan Clarity

- Keeps Switch account and Sign out visible and labeled on the account page.
- Describes Advanced Import as one Pro capability with 30 jobs per calendar
  month. Its one-at-a-time processing boundary is no longer presented as a
  separate membership benefit.

## Review Status

The hosted Checkout page was opened successfully during the final production
smoke, but no new live payment was made in that pass. Publication still
requires the exact public-repository candidate to pass automated gates,
Obsidian's developer-dashboard preview scan, and the product team's clean
install and novice-flow checks.
