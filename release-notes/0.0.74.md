# DocFerry 0.0.74

Corrects missing settings pages on Obsidian 1.13 and later.

## Fixed

Version 0.0.73 registered only four native settings definitions. Newer hosts
rendered those definitions instead of DocFerry's complete settings page.
This version restores Account, Sharing, Imports, and Advanced, including the
account connection, membership information, and direct Shares entry.

The incomplete global-search entries are withdrawn. All preferences remain
available inside DocFerry settings. Both the minimum supported host (1.12.7)
and 1.13.7 have been exercised in isolated real Obsidian windows.

## Update Safety

- Refresh affected XML parser and build-review dependency locks to patched
  versions; no broad dependency or SDK upgrade.
- Same plugin ID: `docferry`; desktop minimum: `1.12.7`.
- No account reset, forced sign-in, token migration, or new permissions.
- No changes to Share content, quotas, subscriptions, or payment amounts.
- Free and optional Pro remain unchanged, including 30 Advanced Imports per
  calendar month. Hosted service: https://docferry.bondie.io.
- Website billing navigation requires a separate server correction. Installing
  this client does not itself repair or enable subscription portal features.

## Review And Installation

This is a draft candidate for product-team approval, not a claim of Community
review completion. See [the reviewer checklist](../docs/reviews/0.0.74.md).
The release workflow builds and attests `main.js`, `manifest.json`, and
`styles.css`. Download all three matching assets for a controlled manual
installation into `.obsidian/plugins/docferry/`, then reload the plugin.
Do not remove `data.json` or other existing configuration.

Publishing this GitHub release can trigger automatic Obsidian review. The
product team controls publication and any developer-dashboard submission.
