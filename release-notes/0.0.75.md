# DocFerry 0.0.75

This corrective release resolves the Community review blocker caused by the
default-branch manifest pointing to the unpublished 0.0.74 draft.

- Stable Community plugin ID: `docferry`.
- Manifest version and public release tag: `0.0.75`, with no `v` prefix.
- Includes `main.js`, `manifest.json`, and `styles.css`, built and attested in CI.
- Restores Account, Sharing, Imports, and Advanced settings on Obsidian 1.13+.
- Includes patched dependency locks from the 0.0.74 candidate.
- Preserves accounts, settings, stored notes, and the 1.12.7 minimum host.
- No changes to authentication, membership, billing amounts, or privacy flows.

The runtime bundle is unchanged from the real-host-tested 0.0.74 candidate.
The previous four incomplete native settings-search entries remain withdrawn
because they replaced the full settings page on newer hosts.

The release workflow now checks that the published release is non-draft,
matches the manifest, and serves byte-identical assets. Official Community
review status remains separate from successful GitHub publication.

Hosted service: https://docferry.bondie.io.
Website billing repairs require the separate server rollout; this release
does not deploy or change the payment portal.
